Raspberry Pi Zero 2W Web Server

Mar 2025- Ongoing

Areas of Knowledge: Cryptography, Linux Networking, C programming, TLS/ Intenet technologies, DBMS

Tools Used: sqlite3, OpenSSL, C, sockets, Ubuntu, Raspberry Pi Zero 2W

Project Cause: Being frustrated with how slow some websites using PHP and MySQL were acting, I decided I would see if I could make a faster alternative. This also gave me the benefits of being able to use C (my favourite programming language) in calculating the dynamic content to be displayed and giving access to the low level features that C has to offer.


I developed a very bare-bones server that came with a library with some tools to make use of SQL slightly easier and a skeleton on which you can customize logic.

I did not work on a complicated website to host using this tool, instead just doing testing for functionality (such as multiple sessions, basic hello worlds, linking in css files etc, logging requests, connection to databases) so that will have to be my next steps.

Save Cyber

Sept 2024-May 2025

Areas of Knowledge: Cyber security, PHP, mySQL, Javascript, game development, HTML, CSS, knowledge sharing

Tools Used: PHP, HTML, CSS, JavaScript, mySQL, XAMPP for web development, Gitlab for collaboration, Obsidian for documentation

Project Cause: This project was completed as coursework for COMP11120 First Year Team Project.

This project was completed over the course of my first year among 5 other team members. I took a leading role in the project's direction and was the main architect of the backend, HTML and CSS. The basic idea is that you are a player who works through a number of paths within cyber security: Social engineering, cryptography and ethical hacking. It comes complete with login systems, achievements, full customization and a forum.

This project received high praise from members of staff, achieving one of 6 awards given in the module by the university and a first class grade.

This project was most beneficial for me in the "soft skills" learned, many about balancing learning and other commitments alongside project work. I also gained a bit more experience with knowledge sharing as the team had a diverse breadth of knowledge and experience. We also gave two presentations and upon receiving the award, I gave a short talk to the whole department about our project.

JW Auctions

Jan 2023- Mar 2023

Areas of Knowledge: Full stack web development, project management, documentation

Tools Used: HTML, CSS, PHP, MySQL

Project Cause: This project was completed as part of my A Level Computer Science coursework.

This website completes the entirety of an e-commerce auctioneering with the exception of the final financial infrastructure to take payments. It is ultimately where my interest in Computer Science really materialised, seeing me abandon the premise of studying Law instead.

This project was my first proper piece of software written by me, having no experience with PHP nor JavaScript. Regardless, I managed to produce a solution I am proud of (despite spending limited time on CSS as it was not considered examinable). Upon completion, I was informed I had received the school's highest ever Computer Science coursework grade (a comfortable A*) and it came complete with the following features:

  • Log in, sign up and sign out features complete
  • Ability for users to create items to list, with configurables such as start price, time limits, buy now options and a tab to track their listings
  • Ability to bid on listings or buy now (though this path ends where the payment would begin)
  • Sanitisation of inputs: no SQL nor XSS injection, limited file sizes, valid emails etc
  • A search algorithm to look for products by words or categories
